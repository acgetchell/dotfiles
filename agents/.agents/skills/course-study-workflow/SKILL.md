# Course Study Workflow

Create and maintain study artifacts from course materials such as lecture slides, textbooks, readings, assignments, notes, and practice questions.

Use this workflow for quizzes, midterms, finals, oral presentations, qualifying exams, cumulative review, and allowed exam-aid preparation.

## Choose the Requested Activity

Use the mode that serves the current request; an outline, quiz, or exam aid does
not require completing the entire study cycle. Infer scope from supplied course
materials and prior conversation. Ask only for missing information that affects
the requested result, such as exam-aid restrictions or grading weights.

- For outlines, summaries, or coverage audits, read [summaries](references/summaries.md).
- For quick recall, drills, or practice assessments, read [practice](references/practice.md).
- For grading, error classification, and targeted re-tests, read [grading and repair](references/grading-and-repair.md).
- For cumulative exam preparation or permitted aids, read [exam aids](references/exam-aids.md).

Preserve instructor terminology and emphasis. Match known assessment formats and
point weights. Report both question accuracy and the point-weighted score when
grading. In retrieval practice, let the learner answer before revealing solutions.
Keep substantive assessed scholarly prose within the academic authorship boundary.

## Source Of Truth

Treat the Markdown outline as the authoritative working document.

Treat rendered documents such as LaTeX, PDF, DOCX, or slides as derived artifacts.

Unless the user explicitly says otherwise:

- Update the Markdown outline first.
- Regenerate or patch rendered documents from the outline.
- Preserve user corrections, quiz-repair material, and instructor-specific emphasis.
- Do not directly edit rendered study notes when the outline should drive them.
