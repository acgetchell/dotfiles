# Standalone Citation Audit Report

Read this reference only when `scientific-citation-audit` is invoked directly
without an exact parent result contract. Review-graph and the documentation
orchestrator already own reporting when they dispatch this skill.

Report:

- citation files and active documentation inspected
- DOI and link validation commands and results, including dead, malformed, or
  metadata-mismatched references
- algorithm and data-structure claims with correct, missing, weak, or misplaced
  credit
- files edited and why
- documentation or configuration validators, or why they were unavailable
- optional literature additions, reading tasks, or citation questions left for
  the maintainer
