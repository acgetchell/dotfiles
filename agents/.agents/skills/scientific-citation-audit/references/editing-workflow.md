# Citation Editing Workflow

Read this reference only when citation fixes are explicitly authorized.

- Preserve the repository's existing reference format.
- Prefer DOI links only after verifying the metadata matches the cited work.
- Use angle links or percent-encoded URLs when DOI strings contain parentheses
  or other Markdown-sensitive characters.
- Keep `REFERENCES.md` as the bibliography owner, but add local source or
  documentation pointers near the algorithm that uses the citation.
- Do not update generated changelogs by hand.
